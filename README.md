
## UhcMeetup

A customizable UhcMeetup plugin for Minecraft!

Fork From https://github.com/Gonzaa3007/UhcMeetup




## Features

- MC Version: 1.21.11+
- Stats & Leaderboard
- MySQL compatibility
- Customizable messages, config, scoreboard and kits
- Random kits


## Commands

`/stats <player>`
- See a player stats

`/topstats`
- Open the TopStats GUI

`/uhcmeetup setlobby`
- Sets the spawn

`/uhcmeetup reload`
- Reload all configs

`/forcestart`
- Starts the Meetup

## Permissions

- meetup.admin
- meetup.forcestart
